# Your 15-Minute Launch Checklist (the only human steps)

Everything else is already built. These are the steps only you can do, in priority order.

## Step 0 — Python check (1 min)
Open a terminal and run `python --version`. Already confirmed on this machine: Python 3.12 ✅

## Step 1 — Test the product yourself (5 min)
1. Put 20 junk files of different types in a temp folder
2. Run: `python dev-tool-pack\scripts\file_organizer.py <that folder> --dry-run`
3. You should see a clean move plan. This is your demo — screenshot it for gig images.

## Step 2 — Fiverr first (the fast path to $50) (5 min)
1. Create/login at fiverr.com → Create a Gig
2. Post **Gig 2** (bulk rename/resize/convert) from `fiverr-gigs.md` — it's the most searched
3. Post **Gig 3** (PDFs) right after
4. Price as written ($15–20). First orders usually come from these within 1–3 days.
   **Each fulfilled order uses the scripts — 10–20 min of work per order.**
