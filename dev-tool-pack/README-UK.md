# GrabKit Desktop — набір інструментів для порядку у файлах

16 готових інструментів, які прибирають рутину: розкласти папку по типах, знайти
дублікати, зменшити фото, з'єднати PDF, перейменувати сотні файлів, зробити бекап.
Все працює на вашому комп'ютері, без інтернету й без акаунтів.

## Як запустити (2 хвилини, один раз)

1. Встановіть Python (безкоштовно): https://python.org/downloads
   На першому екрані обов'язково поставте галочку **«Add python.exe to PATH»**.
2. Для PDF та фото один раз виконайте в терміналі:
   ```
   pip install -r requirements.txt
   ```
   (решта інструментів працює на чистому Python)
3. Двічі клікніть **`Start GrabKit.bat`** — відкриється вікно програми.

Далі все мишкою: вибрали інструмент зліва → вибрали папку → **Run**.
Результат з'явиться у чорному вікні внизу.

## Що всередині

| Інструмент | Що робить |
|---|---|
| Організувати папку | Розкладає файли по теках: Фото / Документи / Музика / Відео / Архіви |
| Знайти дублікати | Знаходить однакові файли за вмістом і показує, скільки місця вони займають |
| Що займає диск | Показує розмір кожної папки — від найбільшої |
| Бекап у ZIP | Робить один архів з датою, нічого не перезаписує |
| Синхронізація папок | Робить другу папку точною копією першої |
| Масове перейменування | Додає префікс, нумерує 001/002, робить нижній регістр |
| Пошук і заміна у файлах | Замінює текст одразу в сотнях файлів (з .bak копіями) |
| Авто-сортування нових файлів | Слідкує за папкою і прибирає все, що туди потрапляє |
| Зменшити / конвертувати фото | Готує фото для пошти, сайту або оголошення; оригінали не змінюються |
| Водяний знак на фото | Ставить ваш текст на всі фото — захист портфоліо й оголошень |
| З'єднати PDF | Кілька PDF в один файл |
| Розбити PDF на сторінки | Один PDF на кожну сторінку |
| Витягнути сторінки з PDF | Залишити тільки потрібні сторінки (напр. 1-3,7) |
| Інформація про PDF | Кількість сторінок, назва, розмір |
| CSV: з'єднати / розбити / переглянути | Робота з таблицями без Excel |
| CSV: дублікати, фільтр, статистика | Прибрати повтори, відібрати рядки, порахувати стовпець |
| Посилання зі сторінки | Витягнути всі посилання у CSV |
| Паролі | Згенерувати надійні паролі локально |

## Безпека

- Нічого не видаляється без вашого підтвердження.
- Майже кожен інструмент спочатку показує план («preview»), і тільки потім змінює файли.
- Нічого не надсилається в інтернет.
