## What is GrabKit?

GrabKit is a pack of 12 small Python scripts that automate the boring file tasks you do every month:

- 📂 **File Organizer** — sorts Downloads into Images / Documents / Audio / Video / Archives in seconds
- 🔍 **Duplicate Finder** — finds duplicate files by *content*, not filename — shows wasted space per group
- 📏 **Folder Size** — see what's eating your disk, largest first
- 💾 **Backup Zip** — one-command timestamped backup of any folder
- ✏️ **Bulk Rename** — rename 500 photos (number, lowercase, prefix) with preview
- 🔄 **Find & Replace** — replace text across hundreds of files, with automatic .bak backups
- 📊 **CSV Toolkit** — merge, split, count, preview CSV files
- 📄 **Text Diff** — compare two text files line by line
- 📑 **PDF Toolkit** — merge, split, extract pages, inspect PDFs
- 🖼️ **Image Resizer** — bulk-resize/convert photos for email or web, originals untouched
- 🔗 **Link Scraper** — pull every link from any web page into CSV
- 🔐 **Password Tools** — generate strong passwords; check how strong one is

## Quick start

```bash
# 1. Install Python (free): https://python.org
# 2. Download GrabKit and unzip
# 3. Open a terminal in the scripts/ folder

# Organize your Downloads folder (preview first):
python file_organizer.py ~/Downloads --dry-run

# Find duplicate files:
python duplicate_finder.py ~/Pictures

# Back up a folder:
python backup_zip.py ~/Documents
```
