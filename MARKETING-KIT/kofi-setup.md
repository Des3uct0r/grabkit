# Ko-fi / Buy Me a Coffee — Setup Guide

## Ko-fi (recommended — lower fees, supports digital downloads)

1. Go to https://ko-fi.com → Sign up (free, uses your email + Stripe/PayPal for payouts)
2. Create a page: name "GrabKit", bio: "12 automation scripts that organize files, find duplicates, resize photos, merge PDFs. $9.99 on Gumroad."
3. Add a "Shop" item: link to your Gumroad product (Ko-fi takes 0% on donations, 5% on shop sales — or 0% with Ko-fi Gold $6/mo)
4. Share your Ko-fi link in your GitHub README, Twitter bio, and Dev.to profile
5. Ko-fi also supports monthly memberships ($3/mo "supporter" tier) — good for recurring revenue

## Buy Me a Coffee (alternative)
1. https://www.buymeacoffee.com → Sign up
2. Set up page, link to Gumroad product
3. Lower barrier than Ko-fi for one-time tips ($3 "coffee")

## Strategy
- Use Ko-fi as a "tip jar" for people who found your free GitHub repo useful
- Link to Gumroad for the full paid pack
- Add a "Support this project" badge to your GitHub README
- Both platforms have built-in email collection (use it to build a list for future products)
