# LinkedIn Post — GrabKit

I spent years writing small Python scripts to clean up my own computer — organizing Downloads folders, finding duplicate photos, zipping backups, resizing images for email.

None of them were clever. None of them were "AI." They were just... useful. The kind of thing you do once a month and hate every time.

So I packaged them into a product.

GrabKit: 12 one-command automation scripts. No coding required — if you can open a terminal and type a line, you can use them. Every tool previews before it changes anything, so nothing gets deleted or overwritten by accident.

What's inside:
→ File Organizer (sorts Downloads into categories in seconds)
→ Duplicate Finder (by content, not filename)
→ Image Resizer (bulk resize, originals untouched)
→ Backup Zip (one-command timestamped backup)
→ Bulk Rename, Find & Replace, CSV Toolkit, PDF Toolkit, Folder Size, Text Diff, Link Scraper, Password Tools

9 of 12 use only Python's built-in libraries. The other 3 tell you the one-line install if you want them. Windows, Mac, Linux.

$9.99 one-time. Lifetime updates. 30-day refund.

The lesson for me: the products that sell aren't always the clever ones. Sometimes they're the boring ones that save 30 minutes on a Saturday.
