## Quick start

```bash
# 1. Install Python (free): https://python.org
# 2. Open a terminal in the scripts/ folder

python find_big_files.py C:\Users\me --top 20
python find_empty_folders.py C:\Users\me
python folder_size_report.py C:\Users\me
```

Requirements: **Python 3.8+**. All tools use only the standard library.
